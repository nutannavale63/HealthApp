What is FDE?

Full-stack Development Experience

FDE is a hands-on, project-based training program designed around the real-world BBHealthApp — a COVID-19 Health Management System — to teach participants how production software is built, deployed, and maintained.

"FDE turns classroom theory into real cloud-native product engineering."

Unlike traditional courses, FDE uses a live, production-grade codebase as the learning canvas — covering frontend, backend, databases, DevOps, and cloud infrastructure all in one program.

  • 🎯Goal-oriented: Learn by building and fixing real features in BBHealthApp
  • 🏗️Architecture-first: Understand microservices before writing a single line of code
  • ☁️Cloud-native: Deploy on AWS EKS with Kubernetes, Helm & CI/CD pipelines
  • 🔐Security-aware: JWT, BCrypt, RBAC, CORS — baked in from day one
  • 🤝Team-based: Git workflows, PR reviews, Jenkins pipelines like a real team
  • 📊Measurable outcomes: Working deployments, documented PRs, and a portfolio
Core Functions

What does FDE do?

🧩

Breaks Down Real Systems

Participants dissect BBHealthApp's 4 microservices — Master, Register, Document & Frontend — to understand how large systems are organised and communicate.

🛠️

Teaches by Doing

Every concept — from JWT auth to Kubernetes rolling updates — is applied directly inside a running project, not toy examples.

🚀

Bridges Dev → Prod

Participants learn the full journey: local Docker Compose → Jenkins CI/CD → AWS ECR → EKS cluster → ALB Ingress with SSL.

🐛

Trains Debugging Skills

Includes real ERROR_LOG.md with documented issues — null token bugs, port conflicts, CORS errors — and teaches systematic root-cause analysis.

📋

Builds Engineering Habits

Enforces proper Git commits, PR reviews, documentation writing (ARCHITECTURE.md), and incident logging — industry-grade engineering habits from day one.

Real-World Context

User Roles in BBHealthApp

FDE participants implement and understand features for 4 distinct user roles — each with different permissions, workflows, and dashboards.

🏥

Patient (USER)

Request COVID tests, book consultations, upload medical documents, view test results & reports.

👨‍⚕️

Doctor

Review pending consultations, view patient test results, provide medical consultation, upload documents.

🧪

Tester

Manage test requests queue, perform tests, update results — positive/negative/quarantine decisions.

🏛️

Government Authority

Approve user registrations, view analytics dashboard, manage system thresholds, oversee all operations.

Role-based access controlled via Spring Security + JWT scopes

For Freshers

How to Prepare as a Fresher

01
🌐

Master Web Basics

HTML, CSS, JavaScript fundamentals. Understand how browsers communicate with servers (HTTP, REST APIs, JSON).

02
⚛️

Learn React Fundamentals

Components, state, props, hooks (useState, useEffect). Practice building small CRUD apps with Axios HTTP calls.

03
☕

Java & Spring Boot Basics

OOP in Java, REST controllers, Maven builds. Create a simple Spring Boot API with H2 database — exactly what BBHealthApp uses.

04
🐳

Docker Essentials

Write a Dockerfile, run containers, understand Docker Compose for multi-service setups. Run BBHealthApp locally.

05
🔀

Git & Collaboration

Branch strategy, pull requests, merge conflicts. Learn Git flow as used in the Jenkins CI/CD pipeline of this project.

06
🔐

Security Concepts

Understand authentication vs authorization, JWT tokens, password hashing with BCrypt, and why CORS matters.

Course Design

Course Focus: Fresher vs Experienced

🌱
Fresher Track
Guided Learning
  • 📖Structured modules with step-by-step labs
  • 🏗️Architecture-first: understand before coding
  • 🧑‍🏫Pair programming with mentors
  • 🐛Guided debugging of ERROR_LOG issues
  • 📋Pre-built tasks: add an API endpoint, fix a bug, write a test
  • ☁️Assisted cloud deployment with Helm & EKS
  • 🏆Portfolio project: a documented PR to BBHealthApp
🚀
Experienced Track
Deep-dive Engineering
  • ⚡Self-paced with advanced design challenges
  • 🏛️Propose and implement architectural improvements
  • 🔒Harden security: CORS restrictions, refresh tokens, rate limiting
  • 📊Add Prometheus/Grafana monitoring stack
  • 🗄️Migrate H2 → PostgreSQL with Flyway migrations
  • 🧪Write integration + end-to-end tests (JUnit, Cypress)
  • 🌐Design and implement the future improvements from docs
